# Наряд

Сайт готовит файл на бланке МВД: уведомление о прибытии, заявление на патент, заявление на вид на жительство, заявление на гражданство. Визит к юристу не нужен. В подразделение файл несёте сами.

Список и заполнение бесплатны. Готовый файл открывается после тестовой оплаты 490 ₽. Деньги не списываются. Это не госпошлина.

## Запуск

```bash
npm install
npm run dev
```

Сайт: http://127.0.0.1:5173 . API: http://127.0.0.1:8787 .

Продакшен:

```bash
npm run build
HOST=127.0.0.1 PORT=8787 npm start
```

Сервер отдаёт `dist` и API. Кабинет лежит в `data/app-store.json` (в git не входит).

## Сверка с МВД

Раз в две недели, 1-го и 15-го числа:

```bash
npm run check:mvd
```

Скрипт заново открывает страницы из `src/data/mvd-sources.json`, пишет `reports/mvd-check-ДАТА.md` и не меняет бланки. Если страница не открылась или текст разъехался, команда завершается с кодом 2. Первый отчёт: `reports/mvd-check-2026-09-25.md`.

## Домен

Приложение стоит на Beget, каталог `/opt/documentmigrant`, процесс `naryad` на `172.18.0.1:8787`. Снаружи его отдаёт уже работающий Caddy. Пока домен не делегирован, сайт открывается по HTTP:

http://109.172.37.155/

Имя `documentmigrant.ru` обслуживается тем же приложением.

Когда регистрация домена завершится, в DNS нужны такие записи:

| Имя | Тип | Значение |
| --- | --- | --- |
| `@` | A | `109.172.37.155` |
| `www` | A | `109.172.37.155` |

После того как эти записи начнут открываться, в Caddyfile уберите префикс `http://` у `documentmigrant.ru` и перезапустите контейнер Caddy: тогда он сам получит сертификат. Фрагмент: `deploy/documentmigrant.caddy`.
